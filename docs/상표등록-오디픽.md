# 상표 등록 — 오디픽 (변리사 없이 직접 하기)

2026-09-10 조사. 소연님이 직접 출원하는 것을 전제로, **거절될 이유를 하나씩 없앤 결과**다.

---

## 1. 유사 상표 조사 결과 — 길이 깨끗하다

거절의 대부분은 "비슷한 상표가 이미 있음"이다. 키프리스에서 여러 방식으로 뒤져봤다.

| 어떻게 찾았나 | 국내 결과 | 판단 |
|---|---|---|
| `오디픽` 정확히 | **0건** | 비어 있음 |
| `오?픽` (오X픽) **42류** | **0건** | ✅ 가장 중요. 42류에 비슷한 게 아예 없다 |
| `?디픽` **42류** | 3건 | 리얼디픽 · 메디픽 ×2 → 첫 소리가 달라 위험 낮음 |
| `ODIPICK` | 1건 | `codipick` — **포기** 상태라 죽은 상표. 막지 못한다 |
| `어디픽` | 0건 | 비어 있음 |
| `오디PICK` | 0건 | 비어 있음 |

**결론: 42류에 오디픽을 막을 상표가 없다.**

## 2. 식별력 — 문제없다
"오디픽"은 사전에 없는 만든 말이다. 흔한 말이나 성질을 나타내는 말이 아니라서,
식별력이 없다는 이유로 거절될 가능성은 낮다.

---

## 3. 진짜 위험은 여기 하나 — 지정상품 작성

특허청은 **소프트웨어 관련 상품에 "무엇에 쓰는 것인지"를 구체적으로 밝히도록** 요구한다.
`컴퓨터소프트웨어` 처럼 막연히 쓰면 보정하라는 통지가 온다.

### 해결책 (반드시 지킬 것)
**특허로 출원 화면 안에서 "고시명칭 검색" 기능으로만 고른다. 직접 타이핑하지 않는다.**

- 고시명칭 = 특허청이 미리 정해둔 상품 이름. 목록에서 고르기만 하면 **거절되지 않는다**
- 고시명칭만 쓰면 출원료도 52,000원 → **46,000원**
- 직접 타이핑한 이름(비고시명칭)이 하나라도 섞이면 값이 오르고 심사도 늦어진다

### 검색창에 넣어볼 말 (42류)
아래 낱말로 검색해 나오는 고시명칭 중 오디픽이 실제로 하는 일만 고른다.

- `비다운로드` → SaaS 관련 명칭이 나온다
- `소프트웨어 개발`
- `웹사이트`
- `컴퓨터 프로그래밍`
- `호스팅`

**10개 이하로** 고른다. 11개부터 개당 2,000원이 붙는다. 많이 넣어도 보호가 넓어지지 않는다.

## 4. 출원할 때 이렇게 (성공률 최대화)

| 항목 | 이렇게 | 왜 |
|---|---|---|
| 상표 유형 | **문자상표** (글자만) | 로고를 넣으면 그 로고 그대로만 보호된다. 글자만이 더 넓다 |
| 상표 이름 | **오디픽** (한글) | 팔로워가 부르는 이름. 발음 같은 영문도 함께 보호받는 편 |
| 분야(류) | **42류 하나만** | 오디픽은 웹서비스다. 2개 하면 값이 두 배 |
| 지정상품 | **고시명칭에서 10개 이하** | 거절 안 되고 값도 싸다 |
| 우선심사 | **신청하지 않음** | 돈만 더 든다. 급할 것 없다 |

## 5. 순서와 비용

1. **출원인코드 발급** — [특허로](https://www.patent.go.kr) → 무료 → 간편인증 → 10분
2. **전자출원** — 상표 출원서 작성
3. **출원료 46,000원** 납부
4. **심사 대기** — 6개월~1년
5. **통과되면 등록료 201,000원** — 2번에 나눠 내면 처음엔 **122,000원**

**지금 나가는 돈: 46,000원**

---

## 6. "거절되면 5만원 날리는 것 아닌가" — 아니다

심사관이 문제를 발견하면 바로 거절하지 않고 **의견제출통지서**를 먼저 보낸다.
2개월 안에 의견서나 보정서를 내면 다시 심사한다. **이 대응은 클로드가 도와줄 수 있다.**

즉 직접 출원의 실제 위험은 "돈을 날린다"가 아니라 "한 번 더 손이 간다" 쪽이다.
그래서 이번 건은 **변리사 없이 직접 하는 것을 권한다.**

---

## 7. 출원 뒤에 할 일
- 출원 사실을 **인스타 소개글이나 사이트에 적지 않는다.** 등록 전에 ®를 쓰면 허위표시가 된다
- 등록되기 전까지는 `™` 표시만 쓸 수 있다
- 심사 진행 상황은 특허로에서 확인할 수 있고, 통지서가 오면 클로드에게 보여주면 된다
