# 가을 야장 — 제가 찾아서 넣은 10곳

전에는 5곳뿐이었는데 **15곳으로 늘렸습니다. 5개 구 전부에 생겼어요.**

찾은 방법: 구글 리뷰 본문에 **'야장 · 평상 · 노천 · 야외에서 구워'** 가 실제로 적힌 곳만 골랐습니다.
"창문 열어서 야장 느낌"처럼 실내인 곳은 뺐어요.
