# 구글 키에 잠금 걸기 (10분)

## 왜 해야 하나
오디픽 사이트 안에는 구글 지도 키가 들어 있다. 이건 원래 공개되는 종류라 문제가 아니다.
**문제는 지금 아무 제한이 없다는 것이다.**

2026-09-10 확인: 남의 사이트인 척 요청해도 그대로 통과했다.
즉 누구나 사이트 소스에서 키를 복사해 자기 서비스에 쓸 수 있고, **요금은 소연님 카드로 나간다.**

잠금을 걸면 **오디픽 주소에서 온 요청만** 통과한다.

---

## 하는 법

### 1단계 — 구글 클라우드 콘솔 열기
https://console.cloud.google.com/apis/credentials 로 들어간다.
소연님 구글 계정(nasoyeon6@gmail.com)으로 로그인.

### 2단계 — 키 찾기
"API 키" 목록에서 **`AIza...XxvQG8`** 로 끝나는 키를 찾아 이름을 누른다.
(여러 개면 뒷자리 `XxvQG8` 인 것)

### 3단계 — 주소 제한 걸기
**"애플리케이션 제한사항"** 에서 **`웹사이트`(HTTP 리퍼러)** 를 고른다.
그리고 **"항목 추가"** 를 눌러 아래 두 줄을 넣는다.

```
https://soyeonna.github.io/*
```
```
https://odipick.netlify.app/*
```

두 번째 줄은 넷리파이를 다시 쓸 때를 대비한 것이다. 안 넣어도 된다.

### 4단계 — 쓸 수 있는 기능 제한
**"API 제한사항"** 에서 **`키 제한`** 을 고르고, 아래 두 개만 체크한다.

- **Places API (New)**
- **Street View Static API**

나머지는 체크 해제. 오디픽은 이 둘만 쓴다.

### 5단계 — 저장
아래 **"저장"** 을 누른다. **적용까지 5분쯤 걸린다.**

---

## 걸고 나서 확인
저장하고 10분 뒤, 사이트에서 아무 매장이나 눌러 **사진이 잘 나오는지** 보면 된다.
사진이 안 나오면 3단계 주소를 잘못 적은 것이니 다시 확인한다.

매일 새벽 자동 작업은 이미 "오디픽에서 왔다"고 알리도록 되어 있어서 **잠금을 걸어도 그대로 돌아간다.**

---

## 예산 알림도 같이 걸어두기 (5분, 권장)
https://console.cloud.google.com/billing → **예산 및 알림** → **예산 만들기**
금액을 **1만원**쯤으로 잡아두면, 그 이상 나올 때 메일이 온다.
지금은 구글 사진을 오디픽 안에 받아둬서 요금이 거의 안 나가지만, 안전장치로 두는 게 좋다.
