# 오디픽 로드맵 — "대전공주만 할 수 있는 것" (2026-09-04)

네이버·카카오·다이닝코드가 절대 못 따라오는 것 = **소연님이 직접 가봤다 + 공주들(팔로워)이 믿는다 + 릴스가 있다 + 가게 사장님들과 관계가 있다.**
아래는 그 네 가지를 서비스 기능으로 바꾸는 순서. 위에서부터 한다.

## 1. 공주 코스 (동네별 하루 코스) — 지금 착수
- 같은 동네 안에서 카페 → 밥 → 술/디저트를 도보 거리로 묶어 "코스"로 보여준다. 좌표·영업시간·소연님 순위가 이미 있어서 자동으로 만들 수 있다.
- 홈에 "동네별 공주 코스", 상세에 "이 가게로 코스 짜기".
- 다음 단계: 소연님이 직접 "이 코스는 진짜" 도장 찍은 코스만 상단(공주 인증 코스).

## 2. 공주 한마디 (가게마다 소연님 육성 한 줄)
- 캡션·구글이 아니라 소연님이 직접 쓰는 한 줄. "여기 두부두루치기는 무조건" 같은 것.
- 폰에서 가게 눌러 바로 적을 수 있는 입력 화면(MY 탭 운영자 모드) → 저장소에 자동 반영.
- 이게 쌓이면 오디픽의 문장은 전부 '공주 목소리'가 된다. 다른 데는 못 베낌.

## 3. 공주들 참여 ("나도 가봤어요")
- 카드에 "가봤어요" 버튼 → 숫자 누적 → "공주들 312명 다녀감" 표시, 공주들 픽 순위 탭.
- 제보 기능(이미 있음)을 눈에 띄게: 폐업·가격 변경 제보하면 다음날 자동 반영.

## 4. 매장 혜택 (오디픽 보고 왔어요)
- 릴스 이벤트를 이미 여러 매장과 하고 있음. 가게에 `혜택` 항목을 달아 "오디픽 보여주면 음료 서비스" 같은 걸 카드에 뱃지로.
- 사장님이 직접 등록하는 신청 폼 → 소연님 승인.
- 수익 모델 후보이기도 함.

## 5. 공유·유입
- 가게마다 카카오톡 공유(사진+한 줄) 버튼, 인스타 스토리용 카드(카드메이커 연결).
- 인스타 프로필 링크 걸기, 릴스 캡션 끝에 "지도·영업시간은 오디픽" 한 줄.

## 6. 여행자용
- "대전 1박2일 공주 코스" 2~3개(성심당·노포·야경). 대전여행 뱃지 123곳으로 구성.

## 정리해야 할 잔여 작업
- 룸 정보: 소연님이 아는 곳 이름으로 채우기.
- 서울식당 커버: 영상 첫 장면 캡처 → 앨범.
- 관광공사 API 키 미등록(관광지 사진용, 급하지 않음).
- 구글 클라우드 무료체험 12월 3일 만료 → 11월 말 일반 계정 전환 알림.
- 인스타 프로필 소개글 개편(공주 취향 큐레이터).
