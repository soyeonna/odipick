# 오디픽 작업 일지

컴퓨터를 바꿔가며 작업하기 때문에, **여기를 읽으면 어디까지 했는지 바로 알 수 있게** 적어둔다.
최신 내용이 맨 위. 작업이 끝날 때마다 한 덩어리씩 추가한다.

---

## 2026-08-31 (오후) — 릴스 자동 동기화 점검

**한 일**
- 자동 실행 설정 파일(`.github/workflows/sync-reels.yml`)을 저장소에 포함시킴. 원래는 제외돼 있어서 자동 동기화가 아예 돌지 않는 상태였음
- 소연님이 GitHub 토큰에 `workflow` 권한 추가, `IG_TOKEN` 시크릿 등록
- 수동 실행으로 실제 동작 확인 → **실패**

**남은 문제 (다음에 할 일)**
- **인스타그램 액세스 토큰이 아직 발급되지 않았다.** `.env`의 `IG_TOKEN`은 자리표시자라 Meta가 거부함 (code 190, Cannot parse access token)
- 해결: `docs/INSTAGRAM.md` 2~3번을 따라 Meta 개발자 앱에서 토큰을 발급받은 뒤
  ① GitHub 저장소 시크릿 `IG_TOKEN` 덮어쓰기 ② 로컬 `.env`에도 같은 값 넣기
- 그 후 수동 실행으로 재확인 필요

## 2026-08-30

**한 일**
- 오디픽 메인 사이트(`index.html`) 완성. 로고·핀·아이콘 이미지 제작
- 릴스 222건에서 맛집 정보를 뽑아 데이터로 정리 (가게명·지역·영업시간·좌표·가격)
- 관리자 입력 화면, 카드메이커, 점검 리포트, 분류 검수표 만듦
- 인스타 릴스 자동 동기화 스크립트, 폐업 감지 스크립트, 토큰 연장 스크립트 작성
- 넷리파이 배포 설정

**고친 것 (커밋 순서대로)**
- 지도에 대전 표시와 주변 도시 라벨 추가
- 영업시간 미확인 표시를 카드에서 빼고 상세 화면으로 이동
- 카카오맵 앱이 없어도 열리게 수정. 릴스 없는 곳은 대체 링크로
- 상세 화면의 큰 사진을 빼고 하단 영상 칸으로 옮김

**정한 것**
- 서비스 이름을 **오디픽(ODIPICK)** 으로 확정. 이전 후보 PLACEPICK은 다른 회사와 겹쳐 폐기
- 데이트코스 기능은 데이터가 더 쌓인 뒤로 미룸
- 맛집 데이터는 공공데이터(localdata.go.kr) 인허가 정보로 수집

**남은 문제**
- `.github/workflows/sync-reels.yml` 이 저장소에 안 올라가 있어서 **릴스 자동 동기화가 실제로 돌지 않는 상태**
- 오디픽 사이트 최종 배포 여부 확인 필요
