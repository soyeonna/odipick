## 2026-09-01 (밤) — 대개편 1단계: 검색 뼈대 수리 ✅

소연님이 정리해온 개편 명세의 1단계(검색 파서·필수조건·지역·시간·예산) 완료.

**고친 것**
- 예산: 금액을 실제로 계산. "4명이고 12만원" → 1인 3만원 (총/1인 구분, 이중 해석 제거)
- 인원: "4명", "부모님 두 분과"(+본인) 인식
- 방문 시각: "오늘 7시" → 19:00 영업 여부로 판정 (openAtMin)
- 부모님·가족 검색에 데이트가 끼지 않음 (조용→데이트 규칙 삭제)
- 필수조건은 점수가 아니라 통과/탈락: 동네(2km)·방문시각 영업·시설(주차 등)·예산·인원·음식종류
- 미확인은 만족으로 치지 않음 — 빈 결과 화면에서 "미확인 포함하기" 선택지로 풀 수 있음
- 장소 유형 분리(ptypeOf): 밥집 검색에 뷰티·쇼핑·체험·카페단독·술집단독 제외
- 동 단위 검색: 그 동네 1순위, 반경 2km까지 후보 (거리 3km 풀기 옵션)
- 조건 칩에 동네·시각·인원·예산 표시 + 개별 삭제 가능
- 근거 태그 중복 제거, "술 마실 곳" 술집 인식, 낱말 전량 불일치 시 0곳 방지

**테스트 결과 (명세 16번)**
- ①둔산동 부모님 4명 12만 주차 19시 → 1곳(대선칼국수, 전 조건 확인) ✅
- ②봉명동 둘 조용히 술 새벽 → 3곳 ✅ ③은행동 1인 1만 → 11곳 ✅
- ⑥대전역 대전다운 → 태화장·희락반점 상위 ✅ ⑨⑩ 빈결과/모호검색 정상 ✅
- 생새우회 → 파도수산&포차 등 2곳 (계절 추천도 이 경로 사용)

**남은 제한**
- 요일 휴무는 아직 미반영 (시간대만 판정)
- 휠체어·유모차 등 접근성 데이터 자체가 없음 (제보 구조 필요, 5단계)
- 코드가 아직 한 파일 안 (구획 주석으로 구분, 파일 분리는 3단계)

**다음: 2단계** — 매장 중복 통합(카카오 place ID), 한 매장에 영상 여러 개 연결, 데이터 구조 정리

## 2026-08-31 (밤) — 릴스 자동 동기화 완성 ✅

**해결됨.** 메타 개발자 앱 없이 릴스를 가져오는 길을 찾았다.

- 인스타그램 공개 프로필 정보 통로(`web_profile_info`)로 최근 게시물의 **shortcode·캡션 전문·조회수·좋아요·댓글·게시시각**을 토큰 없이 받아온다
- `scripts/sync_reels_public.py` 작성. 손으로 다듬은 문구는 덮어쓰지 않고 **새 릴스만 추가**. 썸네일은 320px로 줄여 삽입
- 자동 실행 설정을 파이썬 기반으로 교체. **GitHub 서버에서도 정상 작동 확인** (인스타가 차단하지 않음)
- 로컬 실행 결과 새 릴스 7건 추가 → 사이트 릴스 6개 → 13개
- **덤: 릴스별 조회수 확보.** 공식 내보내기에 없던 값이라 숏폼 성과 분석의 막힌 부분이 뚫렸다 (`data/reels_public.json`)

**메모**
- 이 맥북에 node 없음 → `.mjs` 스크립트는 로컬 실행 불가. 파이썬 경로만 씀
- 파이썬 SSL 인증서가 없어 `curl` 로 우회 (설치 불필요)
- `IG_TOKEN` 시크릿은 이제 불필요. 메타 개발자 등록도 중단해도 됨
- 이 방식은 비공식 통로라 인스타가 바꾸면 깨질 수 있음

**다음에 할 일**
- 과거 릴스 전체를 넣을지 결정 (`--all`, 383개 중 릴스만). 자동 추출 문구 품질 확인 후 판단
- 새로 들어온 7건의 후킹 문구·가게 이름 손보기
