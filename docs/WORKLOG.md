## 2026-08-31 (밤) — 릴스 자동 동기화 완성 ✅

**해결됨.** 메타 개발자 앱 없이 릴스를 가져오는 길을 찾았다.

- 인스타그램 공개 프로필 정보 통로(`web_profile_info`)로 최근 게시물의 **shortcode·캡션 전문·조회수·좋아요·댓글·게시시각**을 토큰 없이 받아온다
- `scripts/sync_reels_public.py` 작성. 손으로 다듬은 문구는 덮어쓰지 않고 **새 릴스만 추가**. 썸네일은 320px로 줄여 삽입
- 자동 실행 설정을 파이썬 기반으로 교체. **GitHub 서버에서도 정상 작동 확인** (인스타가 차단하지 않음)
- 로컬 실행 결과 새 릴스 7건 추가 → 사이트 릴스 6개 → 13개
- **덤: 릴스별 조회수 확보.** 공식 내보내기에 없던 값이라 숏폼 성과 분석의 막힌 부분이 뚫렸다 (`data/reels_public.json`)

**메모**
- 이 맥북에 node 없음 → `.mjs` 스크립트는 로컬 실행 불가. 파이썬 경로만 씀
- 파이썬 SSL 인증서가 없어 `curl` 로 우회 (설치 불필요)
- `IG_TOKEN` 시크릿은 이제 불필요. 메타 개발자 등록도 중단해도 됨
- 이 방식은 비공식 통로라 인스타가 바꾸면 깨질 수 있음

**다음에 할 일**
- 과거 릴스 전체를 넣을지 결정 (`--all`, 383개 중 릴스만). 자동 추출 문구 품질 확인 후 판단
- 새로 들어온 7건의 후킹 문구·가게 이름 손보기
- 인스타 프로필 소개글 확정

## 2026-08-31 (저녁) — 메타 등록 막힘 · 대안 검증

**확인한 것**
- 메타 개발자 등록이 이메일 인증 단계(Contact info)에서 하루 반째 반복. 사파리·크롬·시크릿창 모두 동일
- **토큰 없이 릴스 캡션을 읽던 방식(`read-reel.mjs`)은 더 이상 작동하지 않는다.** 인스타 공개 임베드가 자바스크립트 렌더링으로 바뀌어 HTML에 캡션이 없음 (응답 200, 620KB, 캡션 블록 없음). 검증 완료
- **이 맥북에 node가 설치돼 있지 않다.** `scripts/`의 `.mjs` 파일들은 로컬에서 실행 불가. 파이썬 버전(`sync_reels.py`, `build_dist.py`, `refresh_token.py`)만 동작
- `index.html`의 `<script id="reels">` 블록에는 현재 6건만 수동 등록돼 있음 (source: manual)

**결론 / 다음에 할 일**
- 릴스 자동 반영 경로 후보: ① 메타 개발자 앱(막힘) ② 인스타 "내 정보 다운로드"로 주기 반영(개발자 앱 불필요) ③ admin.html 수동 입력
- 소연님 선택 대기 중

## 2026-08-31 (오후) — 릴스 자동 동기화 점검

**한 일**
- 자동 실행 설정 파일(`.github/workflows/sync-reels.yml`)을 저장소에 포함시킴. 원래는 제외돼 있어서 자동 동기화가 아예 돌지 않는 상태였음
- 소연님이 GitHub 토큰에 `workflow` 권한 추가, `IG_TOKEN` 시크릿 등록
- 수동 실행으로 실제 동작 확인 → **실패**

**남은 문제 (다음에 할 일)**
- **인스타그램 액세스 토큰이 아직 발급되지 않았다.** `.env`의 `IG_TOKEN`은 자리표시자라 Meta가 거부함 (code 190, Cannot parse access token)
- 해결: `docs/INSTAGRAM.md` 2~3번을 따라 Meta 개발자 앱에서 토큰을 발급받은 뒤
  ① GitHub 저장소 시크릿 `IG_TOKEN` 덮어쓰기 ② 로컬 `.env`에도 같은 값 넣기
- 그 후 수동 실행으로 재확인 필요
