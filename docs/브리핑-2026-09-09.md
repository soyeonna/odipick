## ⚠️ 걱정되는 것

1. **넷리파이 배포가 어제 오후부터 멈춰 있었음.** 15시에 넣은 코스 뒤로가기도 사이트에 없었음. 폰에서 "가격대 정보가 아직 없어요" 같은 옛 문구가 보인 이유. 넷리파이 로그를 못 봐서 원인은 모름 → 설정을 "빌드 없이 dist 그대로"로 바꿔 올림. **오늘 아침 사이트에 "← 뒤로" 버튼이 보이면 해결된 것.** 안 보이면 넷리파이 대시보드 → Deploys 에서 실패 로그 확인 필요
2. 가격대 198곳은 **추정치**. 틀린 곳은 `data/budget-review.json` 보고 알려주시면 고침 (예: 카페인데 2–3만원으로 잡힌 곳)
3. 인원 필터도 추정(단체석·룸·예약 여부 기준). 실제 수용 인원 데이터는 없음
4. 카드에 구글 사진이 많이 뜨면 구글 사진 요금이 나갈 수 있음 (Places 사진 API). 방문자가 늘면 확인 필요
5. 좌표 수정 중 '수미가'가 공주(31km)로 잡힘 — 카카오 번호가 공주 지점일 수 있음. 확인 필요
6. 폰 사파리가 옛 화면을 캐시로 들고 있을 수 있음 → 새 배포 뒤에도 옛 화면이면 한 번 새로고침 길게 누르기
