# 검토 필요 — 매장 위치·업종

이름·동네·업종이 모두 맞는 매장을 못 찾아 비워둔 곳이다.
엉뚱한 위치를 보여주는 것보다 낫다고 판단했다. 카카오맵 주소를 알려주시면 넣는다.

- **남영동양문** (선화동) — 다른 지역 좌표
- **은주** (봉명동) — 엉뚱한 업종
- **케이찹사라다** (대흥동) — 다른 지역 좌표
- **군산오징어** (세종) — 다른 지역 좌표
- **귯걸귯보이** (둔산동 1063) — 다른 지역 좌표
- **을지면옥** (중리동) — 다른 지역 좌표
