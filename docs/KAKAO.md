# 카카오 API 연결하기

오디픽에 지도를 켜고, 가게 정보를 자동으로 채우기 위한 절차입니다.
**전부 무료이고 심사가 없습니다.** 10분이면 끝납니다.

> **먼저 알아둘 것 — 키가 두 개입니다.**
> 하나의 앱에서 두 종류의 키가 나오고, 쓰는 곳이 다릅니다. 이것만 헷갈리지 않으면 됩니다.
>
> | 키 | 쓰는 곳 | 어디에 두나 |
> |---|---|---|
> | **JavaScript 키** | 화면에 지도 그리기 | 웹페이지 안 (공개돼도 됨, 도메인으로 잠금) |
> | **REST API 키** | 가게 검색·좌표 채우기·폐업 확인 | 내 컴퓨터·서버에만 (절대 공개 금지) |

---

## 1. 가입하고 앱 만들기

1. <https://developers.kakao.com> 접속 → 카카오 계정으로 로그인
2. 상단 **내 애플리케이션** → **애플리케이션 추가하기**
3. 입력할 것
   - 앱 이름: `ODIPICK`
   - 회사명: `대전공주` (개인도 아무거나 적으면 됩니다)
4. 저장

## 2. 키 두 개 복사해두기

만들어진 앱을 클릭 → 왼쪽 메뉴 **앱 키**

- **JavaScript 키** — 지도용
- **REST API 키** — 검색용

두 개 다 복사해서 메모장에 잠깐 붙여두세요.

## 3. 지도를 쓰려면 두 가지 설정이 필요합니다

**(1) 카카오맵 켜기**
왼쪽 메뉴 **카카오맵** → **활성화 설정**을 **ON**

> ⚠️ 무료 사용량은 **개발자 계정에서 처음 활성화한 앱 하나에만** 주어집니다.
> 앱을 여러 개 만들지 마세요. 오디픽 앱 하나로 계속 쓰면 됩니다.

**(2) 도메인 등록**
왼쪽 메뉴 **플랫폼** → **Web 플랫폼 등록** → 사이트 주소 입력

아직 도메인이 없으면 지금은 아래 두 개만 넣어두세요. 나중에 실제 주소가 생기면 추가하면 됩니다.

```
http://localhost:8000
http://127.0.0.1:8000
```

**등록 안 한 주소에서는 지도가 안 뜹니다.** 지도가 회색으로만 나오면 십중팔구 이것 때문입니다.

## 4. 저에게 알려주실 것

- **JavaScript 키** — 이건 어차피 웹페이지에 들어가서 공개되는 값이라 채팅으로 주셔도 됩니다.
- **REST API 키** — **채팅에 붙여넣지 마세요.** 아래처럼 파일로 만들어 두시면 제가 그 파일을 읽어 씁니다.

```
claude-work/odipick/.env
```

파일 안에 이렇게 한 줄:

```
KAKAO_REST_KEY=여기에REST키
```

## 5. 그다음은 제가 합니다

키가 준비되면 이렇게 진행됩니다.

| | 무엇이 되나 |
|---|---|
| 지도 | 가게 상세에 실제 카카오맵이 뜨고 길찾기가 연결됩니다 |
| 좌표·주소 | 가게 이름만 넣으면 주소·좌표·전화번호가 자동으로 채워집니다 |
| 폐업 감지 | 폐업하면 카카오 검색에서 사라지므로 정확하게 잡아냅니다 |
| 주변 검색 | "지금 내 위치에서 가까운 곳" 같은 기능이 가능해집니다 |

---

## 안 되는 것도 미리 말씀드립니다

카카오도 **룸 유무 · 단체석 · 수용 인원 · 분위기 · 메뉴 가격은 주지 않습니다.**
주소 · 좌표 · 전화번호 · 카테고리 · 영업 여부까지입니다.

그 나머지가 오디픽에만 있는 정보고, 그래서 그게 이 서비스의 이유입니다.

## 사용량

로컬 API(검색)는 **하루 10만 건 무료**입니다.
대전 음식점을 전부 훑어도 하루 안에 끝나고 요금이 발생하지 않습니다.
