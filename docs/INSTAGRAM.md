# 릴스 자동 동기화 설정

인스타그램에 릴스를 올리면 ODIPICK이 알아서 가져오게 만드는 절차입니다.
**한 번만 설정하면 그 뒤로는 손댈 일이 없습니다.** 이미 올라와 있는 릴스도 첫 실행에서 전부 들어옵니다.

소연님이 하실 일은 1~3번이고, 나머지는 자동입니다.

---

## 1. 인스타그램 계정을 프로페셔널로

이미 되어 있을 가능성이 높습니다 (광고 문의를 받고 계시니까).

> 인스타그램 앱 → 설정 → 계정 종류 및 도구 → **프로페셔널 계정으로 전환**
> 크리에이터 / 비즈니스 둘 다 됩니다.

개인 계정은 2026년부터 어떤 공식 API로도 접근이 안 됩니다. 이 단계는 건너뛸 수 없습니다.

## 2. Meta 개발자 앱 만들기

1. <https://developers.facebook.com> 접속 → 우측 상단 **내 앱** → **앱 만들기**
2. 사용 사례에서 **Instagram** 선택
3. 만들어진 앱에서 **Instagram → API 설정** 으로 들어가기
4. **Instagram 계정 연결** 눌러서 `@_princesspick_` 로그인
5. 권한은 `instagram_business_basic` 만 있으면 됩니다

## 3. 토큰 받아서 넣기

같은 화면에서 **액세스 토큰 생성** 을 누르면 긴 문자열이 나옵니다. 그게 토큰입니다.

- 이 토큰은 **60일 뒤 만료**됩니다
- 자동 갱신 스크립트를 넣어놨으니 방치해도 됩니다 (`scripts/refresh-token.mjs`)
- 토큰은 비밀번호와 같습니다. **아무한테도 보내지 마세요.** 저한테도 보내실 필요 없습니다

토큰을 저장소 시크릿에 넣습니다:

> GitHub 저장소 → Settings → Secrets and variables → Actions
> → **New repository secret** → 이름 `IG_TOKEN`, 값에 토큰 붙여넣기

---

## 그다음은 자동입니다

`.github/workflows/sync-reels.yml` 이 **매일 아침 6시(한국시간)** 에 돌면서:

1. 인스타그램에서 릴스를 전부 가져옵니다 (페이지 넘겨가며 전량, 기존 게시물 포함)
2. 캡션 첫 줄을 후킹 문구로, 해시태그에서 지역을 뽑아냅니다
3. `index.html` 안의 릴스 데이터만 갈아끼웁니다
4. 바뀐 게 있을 때만 커밋합니다

새 릴스를 올리면 **다음 날 아침에 사이트에 자동으로 들어와 있습니다.**
급하면 GitHub Actions 탭에서 **Run workflow** 를 눌러 즉시 실행할 수 있습니다.

## 지금 바로 한 번 돌려보려면

```bash
IG_TOKEN=여기에토큰 node scripts/sync-reels.mjs
```

`릴스 381개 동기화 완료` 같은 메시지가 나오면 성공입니다.

## 가져오는 것 / 못 가져오는 것

| 항목 | 자동 | 비고 |
|---|---|---|
| 릴스 영상·썸네일 | O | 공식 임베드로 사이트에서 바로 재생 |
| 캡션 · 후킹 문구 | O | 첫 줄을 자동 추출 |
| 좋아요 · 댓글 수 | O | |
| 게시 시각 | O | 최신순 정렬에 사용 |
| 지역 (동 이름) | 부분 | 해시태그에 있을 때만 |
| **가게 이름** | X | 캡션마다 형식이 달라 자동 추출이 부정확합니다 |
| **룸 · 주차 · 인원 · 예산** | X | 인스타그램에 없는 정보입니다 |

마지막 두 줄이 사람 손이 필요한 부분이고, 그게 이 서비스의 유일한 해자입니다.
자동으로 긁을 수 있었으면 남들도 벌써 다 했습니다.

## 토큰이 만료됐을 때

사이트는 그대로 돌아갑니다 (데이터가 이미 파일에 들어있으니까).
새 릴스만 안 들어옵니다. 2번 화면에서 토큰을 다시 만들어 `IG_TOKEN` 시크릿을 덮어쓰면 됩니다.
