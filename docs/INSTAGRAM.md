# 릴스 자동 동기화

인스타그램에 릴스를 올리면 오디픽이 알아서 가져옵니다.
**설정할 게 없습니다.** 메타 개발자 앱, 토큰, 로그인 전부 필요 없습니다.

---

## 어떻게 되는 건가

인스타그램이 누구에게나 공개하는 프로필 정보를 그대로 읽어옵니다.
`@_princesspick_` 는 공개 계정이라 별도 권한이 필요 없습니다.

**매일 아침 6시(한국시간)** 에 자동으로 돌면서:

1. 최근 게시물을 확인합니다
2. 아직 오디픽에 없는 릴스만 골라냅니다
3. 캡션에서 후킹 문구와 가게 이름을 뽑고, 썸네일을 넣습니다
4. 바뀐 게 있을 때만 저장합니다

**이미 손으로 다듬어 둔 문구는 절대 덮어쓰지 않습니다.** 새 릴스만 추가합니다.

## 급할 때 바로 돌리기

```bash
python3 scripts/sync_reels_public.py
```

옵션:

| 명령 | 하는 일 |
|---|---|
| `python3 scripts/sync_reels_public.py` | 최근 것 확인해서 새 릴스 추가 |
| `python3 scripts/sync_reels_public.py --all` | 과거 릴스까지 전부 훑기 |
| `python3 scripts/sync_reels_public.py --dry` | 안 고치고 뭐가 바뀔지만 보여주기 |

GitHub 저장소 Actions 탭의 **Run workflow** 버튼으로도 즉시 실행됩니다.

---

## 덤으로 얻는 것 — 릴스별 조회수

`data/reels_public.json` 에 릴스마다 **조회수·좋아요·댓글 수·게시 시각**이 쌓입니다.
인스타그램 공식 데이터 내보내기에는 **릴스별 조회수가 없어서** 그동안 성과 분석이 막혀 있었는데,
이 방식으로는 조회수가 나옵니다. 어떤 릴스가 잘 됐는지 비교할 수 있습니다.

## 가져오는 것 / 못 가져오는 것

| 항목 | 자동 | 비고 |
|---|---|---|
| 릴스 영상·썸네일 | O | |
| 캡션 전문 | O | 가게 이름·주소·영업시간·가격 다 들어있음 |
| 조회수 · 좋아요 · 댓글 수 | O | |
| 게시 시각 | O | 최신순 정렬에 사용 |
| 후킹 문구 | 대략 | 캡션 첫 줄에서 자동 추출. 다듬을 여지 있음 |
| 가게 이름 | 대략 | 📍 표시를 기준으로 추출. 형식이 다르면 비어 있을 수 있음 |
| **룸 · 주차 · 인원 · 예산** | X | 인스타그램에 없는 정보 |

마지막 줄이 사람 손이 필요한 부분이고, 그게 이 서비스의 유일한 해자입니다.

---

## 주의할 점

이건 인스타그램 **공식 API가 아닙니다.** 공개 페이지가 쓰는 통로를 그대로 이용합니다.
인스타그램이 구조를 바꾸면 언젠가 안 될 수 있습니다.
그때는 `scripts/sync_reels_public.py` 를 고치거나, 메타 개발자 앱 방식으로 돌아가면 됩니다.

예전 방식(`sync-reels.mjs`, `refresh-token.mjs`)은 참고용으로 남겨뒀습니다.
`IG_TOKEN` 은 더 이상 쓰지 않습니다.
