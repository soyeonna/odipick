# 사진 없는 가게에 "가게 앞 거리 사진" 붙이기 (구글 스트리트뷰)

사진이 없는 가게 카드에 구글 스트리트뷰(거리 사진)를 자동으로 붙이는 기능이 준비돼 있어요.
**구글 키 하나만 넣으면 켜집니다.** 저작권 걱정 없음 (구글이 API로 쓰라고 제공하는 사진).
매달 200달러 무료 크레딧이 있어서 오디픽 규모에서는 요금이 나오지 않아요.

## 소연님이 할 일 (10분)
1. https://console.cloud.google.com 접속 → 구글 계정 로그인
2. 위쪽 "프로젝트 선택" → "새 프로젝트" → 이름 `odipick` → 만들기
3. 왼쪽 메뉴 "API 및 서비스" → "라이브러리" → **Street View Static API** 검색 → "사용"
4. 결제 계정 연결 (카드 등록 필요. 무료 크레딧 안에서 쓰면 청구 없음)
5. "API 및 서비스" → "사용자 인증 정보" → "사용자 인증 정보 만들기" → "API 키"
6. 만들어진 키 옆 연필(수정) →
   - 애플리케이션 제한: **웹사이트** → `https://soyeonna.github.io/*` 추가 (이렇게 해두면 남이 키를 훔쳐도 못 씀)
   - API 제한: **Street View Static API** 만 선택
7. 키를 복사해서 저한테 "구글 키 넣어줘" 하고 붙여주세요 (채팅에 붙여도 되는 종류의 키예요. 웹사이트 제한을 걸었기 때문)

## 넣으면 어떻게 되나
- 사진 없는 카드에 가게 앞 거리 사진이 붙고, 아래에 "사진: Google 스트리트뷰"라고 표시돼요.
- 골목이라 스트리트뷰가 없는 곳은 그냥 사진 없이 나와요.
