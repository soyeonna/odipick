## 적는 법 (이렇게만 주시면 됩니다)

```
새벽소 / 룸O 주차X 조용함
커닝 / 조용함 노트북가능
계인기 / 주차O 룸X 시끄러움
```

O = 있음 · X = 없음 · 모르면 그냥 빼고 쓰기.
네이버 리뷰 화면을 통째로 복사해 붙여넣어도 제가 읽고 뽑습니다.
