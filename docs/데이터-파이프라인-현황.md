## 3. 지금 당장 위험한 것 하나 — 구글 키 노출

`index.html` 안에 `GOOGLE_KEY='AIzaSy…'` 가 그대로 들어 있고, 화면에서 **사진 URL과 거리뷰**를 만드는 데 씁니다. 배포본이니 누구나 소스 보기로 볼 수 있습니다.

- **이게 곧바로 사고는 아닙니다** — 구글 지도 계열은 원래 브라우저 키를 쓰게 돼 있고, **HTTP 리퍼러 제한**(soyeonna.github.io 에서만 허용)을 걸어두면 남이 가져가도 못 씁니다.
- **소연님이 확인해 주셔야 할 것**: Google Cloud 콘솔 → 사용자 인증 정보 → 이 키 → "애플리케이션 제한사항"이 **HTTP 리퍼러**로 돼 있고 `https://soyeonna.github.io/*` 만 허용돼 있는지. 제가 여기서는 볼 수 없습니다.
- 제한이 없다면 누가 키를 복사해 Places 호출을 돌려 **소연님 요금**이 나갈 수 있습니다.
- 근본 해결은 사진·거리뷰 URL을 Supabase Edge Function 뒤로 옮기는 것. 다만 리퍼러 제한이 걸려 있으면 급하지 않습니다.

Supabase 공개키(`sb_publishable_…`)도 화면에 있지만, 그건 **쓰기 전용 규칙이 걸린 공개용 키**라 설계상 맞습니다.

## 5. 모든 값에 붙어야 할 것

`값 · 출처 · 확인일 · 신뢰등급 · 직접확인 여부 · 충돌 여부` — 지금은 `evidence[]`, `ownerCheckedAt`, `gAt` 로 **일부만** 있습니다. 필드마다가 아니라 가게 단위로 붙어 있어서, "주차는 소연님 확인, 영업시간은 구글"처럼 **값별로 출처를 가르지 못합니다.** Supabase로 옮길 때 값 단위로 바꿔야 합니다.
