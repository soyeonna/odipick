# 오디픽 사업 방향 (2026-09-04 초안)

## 한 줄 정의
"대전공주가 직접 확인한 곳만" — 양이 아니라 신뢰를 파는 지역 큐레이션 플랫폼.
네이버·카카오와 싸우지 않는다. 그들은 '전부'를 보여주고, 오디픽은 '갈 만한 곳만' 보여준다.

## 돈이 나오는 길 (현실적인 순서)
1. 매장 제휴 "오디픽 혜택" (3개월 안에 시작)
   - 찐 기준을 통과한 매장에만 제안. 월 5~10만원에 카드 상단 '혜택' 뱃지 + "오디픽 보여주면 ○○ 서비스" + 릴스 연계.
   - 광고는 반드시 '제휴' 표시. 신뢰가 상품이므로 돈 받고 순위를 파는 순간 끝난다.
   - 목표: 6개월 20곳 → 월 100만원.
2. 릴스 + 오디픽 등록 패키지
   - 이미 하는 릴스 협찬에 "오디픽 등록·혜택 노출·코스 편입"을 묶어 단가를 올린다.
3. 대전시·관광공사 사업 (B2G)
   - 공식 홍보대사 + 실제 서비스가 있는 크리에이터는 드물다. "대전 여행 큐레이션" 용역·협찬 제안.
   - 필요한 것: 방문자 수, 저장 수, 여행 코스 이용 수 같은 숫자.
4. 다음 단계(1년 뒤): 다른 도시 복제 — '○○공주' 크리에이터와 같은 틀을 공유하는 네트워크.

## 목표 숫자
| 시점 | 목표 |
|---|---|
| 3개월 | 사이트 월 방문 1만 · 인스타 프로필 링크 전환 시작 · 혜택 매장 10곳 · 찐맛집 450곳 · 저장 데이터 축적 |
| 6개월 | 제휴 20곳(월 100만) · 팔로워 4만 · 대전시/관광공사 제안서 1건 · 여행 코스 공개 |
| 12개월 | 월 300~500만(제휴 30곳 + 릴스 패키지 + B2G 1건) · 다른 지역 1곳 파일럿 |

## 지켜야 할 것
- 찐 기준(직접 방문·노포·소연님 인증) 밖의 곳은 돈을 받아도 안 넣는다.
- 모든 숫자를 잰다: 방문, 저장, 코스 열람, 매장 상세 조회, 인스타→사이트 전환.
- 팔로워를 서비스로 데려온다: 릴스 캡션 끝에 "지도·영업시간은 오디픽", 프로필 링크.

## 당장 만들 것 (로드맵과 연결)
- 매장 혜택 뱃지 + 사장님 신청 폼 (로드맵 4번)
- 방문·저장·코스 숫자 집계 화면 (MY 탭 운영자 모드)
- 공주 한마디 (로드맵 2번) — 다른 곳이 못 베끼는 콘텐츠
