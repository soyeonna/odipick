# 릴스 업데이트 — 크롬으로 읽어오기

## 왜 자동이 멈췄나
인스타그램이 2026년 9월부터 **로그인 없이 프로필을 읽는 것을 막았다.**
그래서 매일 새벽 자동 작업(`sync_reels_public.py`)이 실패하고 있다. 코드 문제가 아니라 인스타 정책 변경이다.

## 지금 되는 방법 — 소연님 크롬으로
소연님이 인스타에 **로그인한 크롬**이면 릴스를 읽을 수 있다.
클로드에게 "**릴스 업데이트해줘**" 라고 하면, 소연님 크롬을 열어

1. `instagram.com/_princesspick_/reels/` 를 연다
2. 화면을 내리며 새 릴스 번호를 모은다
3. 릴스마다 캡션(가게 이름·주소·영업시간·메뉴 가격)을 읽는다
4. 오디픽에 매장으로 넣고 배포한다

소연님이 할 일은 **크롬에 인스타 로그인 상태만 유지**하는 것뿐이다.

## 얼마나 자주
새 릴스를 올린 뒤 아무 때나. 한 번에 몰아서 해도 된다.

## 앞으로
자동으로 되게 하려면 인스타 개발자 토큰(IG_TOKEN)을 다시 발급받아야 한다.
토큰은 60일마다 갱신해야 하고, 발급 절차가 번거로워 지금은 크롬 방식이 낫다고 판단했다.
