# 릴스 커버 자동 반영 — 즐겨찾기 버튼 (토큰 없음)

새 릴스를 올린 뒤 **인스타 릴스 화면에서 즐겨찾기 버튼 한 번**만 누르면, 그날 새벽 자동 작업이 커버를 오디픽에 붙인다.
메타 개발자 토큰·앨범 캡처가 필요 없다.

## 한 번만 설정 (맥북 크롬, 2분)
1. 크롬 즐겨찾기 바 보이게: `⌘ + Shift + B`
2. 즐겨찾기 바 빈 곳 **오른쪽 클릭 → 페이지 추가**
3. 이름: `오디픽 커버` / URL 칸에 아래 한 줄을 **통째로** 붙여넣기 → 저장

```
javascript:(function(){var o={};document.querySelectorAll('a[href*="/reel/"]').forEach(function(a){var m=a.getAttribute('href').match(/\/reel\/([^\/]+)/);if(!m)return;var es=a.querySelectorAll('*');for(var i=0;i<es.length;i++){var b=getComputedStyle(es[i]).backgroundImage;var u=b&&b.match(/url\("?(https:[^")]+cdninstagram[^")]+)"?\)/);if(u&&!/rsrc\.php/.test(u[1])){o[m[1]]=u[1];break;}}});var n=Object.keys(o).length;if(!n){alert('인스타 릴스 목록 화면에서 눌러주세요');return;}location.href='https://soyeonna.github.io/odipick/cover-drop.html#'+encodeURIComponent(JSON.stringify(o));})();
```

## 쓰는 법 (새 릴스 올릴 때마다, 10초)
1. 크롬에서 `instagram.com/_princesspick_/reels/` 열기 (로그인 상태)
2. 화면에 새 릴스 커버가 보이면 즐겨찾기 바의 **오디픽 커버** 클릭
3. "커버 N개 보냈어요" 페이지가 뜨면 끝. 다음날 새벽 5시 반에 자동으로 붙는다.

- 화면에 보이는 것만 보내므로, 최근 릴스(맨 위 12개쯤)가 대상이다. 옛날 것까지 보내려면 스크롤을 내린 뒤 누르면 된다.
- 이미 커버가 있는 릴스는 자동으로 건너뛴다. 여러 번 눌러도 문제없다.
- 폰에서는 안 된다(즐겨찾기 실행이 막혀 있음). 맥북 크롬으로.

## 뒤에서 도는 것
- `cover-drop.html` — 보낸 주소를 데이터베이스(recommendation_logs, `__cover__`)에 저장
- `scripts/pull_reel_covers.py` — 매일 새벽 daily-care 에서 주소를 받아 `img/<릴스코드>.webp` 로 저장, 릴스 선반·카드 커버에 반영
- 주소는 며칠이면 만료되므로 누른 다음날 자동으로 처리되는 구조가 중요하다.
