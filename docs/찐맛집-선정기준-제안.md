# 오디픽 "찐 현지인 맛집" 선정 기준 (제안, 2026-09-03)

## 목표
네이버처럼 "많이 검색된 곳"이 아니라, **대전 사는 사람이 진짜 가는 곳**만 300~500곳.
프랜차이즈·팝업·광고성 매장은 전부 제외.

## 어떤 근거로 고를 것인가 (점수 아님, 통과/탈락)

| 순서 | 근거 | 설명 | 현재 보유 |
|---|---|---|---|
| 1 | **대전공주 직접 방문** | 릴스에 실제로 나온 곳. 소연님이 발로 확인한 1차 인증 | 200곳 |
| 2 | **노포 (인허가 20년 이상)** | 공공데이터 인허가일자 기준. 20년 넘게 한자리에서 버틴 곳은 동네 사람이 먹여 살린 곳 | 75곳 |
| 3 | **소연님 직접 인증** | 릴스는 없지만 소연님이 "여기 찐"이라고 확인해준 곳 (이번 사진첩 검토처럼) | 진행 중 |
| 4 | **동네 사람 제보 누적** | 사이트 '제보' 기능으로 같은 가게가 2번 이상 "가봤는데 맞다"로 쌓이면 후보 → 소연님 확인 후 등록 | 기능 있음, 데이터 0 |
| 5 | **방송·백년가게 지정** | 백년가게(중기부)·생활의달인 등 공식 기록이 있는 곳. 보조 근거로만 | 태화장·희락반점 등 |

**탈락 조건 (하나라도 걸리면 제외)**
- 프랜차이즈·체인 (본사 있는 브랜드, 지점 3곳 이상)
- 팝업·기간 한정
- 폐업·휴업 확인
- 협찬·광고 릴스만 있고 재방문 근거 없음

## 20,000곳 공공 아카이브는?
- 기본 목록·추천·지도에서 **빼고**, 상호명 검색했을 때만 "등록 안 된 곳" 으로 보여주는 백업으로 둔다.
- 노포 후보 찾을 때(인허가일 20년+) 재료로만 쓴다.
