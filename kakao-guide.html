카카오 키 받기

오디픽에 지도를 켜고 가게 정보를 자동으로 채우기 위한 준비입니다. 화면에 보이는 대로만 따라가시면 됩니다.

전부 무료심사 없음10분

시작 전에 — 키가 두 개입니다

앱 하나에서 키가 두 종류 나옵니다. 쓰는 곳이 달라요. 이것만 헷갈리지 않으면 나머지는 쉽습니다.

JavaScript 키 화면에 지도를 그리는 용도 웹페이지에 들어가서 어차피 공개됩니다. 채팅으로 주셔도 괜찮아요.
REST API 키 가게 검색·좌표 채우기·폐업 확인 용도 비밀번호와 같습니다. 채팅에 붙여넣지 마세요.
1

앱 만들기

developers.kakao.com 에 카카오 계정으로 로그인합니다.

내 애플리케이션→애플리케이션 추가하기
앱 이름은 ODIPICK, 회사명은 대전공주 로 적으시면 됩니다. 아무거나 적어도 상관없어요.
2

키 두 개 복사하기

만들어진 앱을 누르고, 왼쪽 메뉴에서 찾습니다.

앱→플랫폼 키
여기에 REST API 키 · JavaScript 키 · 네이티브 앱 키가 함께 있습니다. 앞의 두 개만 복사해서 메모장에 붙여두세요.
"앱 키" 메뉴를 찾고 계신다면

2025년 12월에 카카오가 화면을 바꿔서 그 메뉴는 없어졌습니다. 지금은 플랫폼 키가 그 자리입니다. 요약 정보 화면에서도 보입니다.

키를 종류마다 5개까지 만들 수 있게 바뀌었는데, 우리는 기본 키 하나씩만 쓰면 됩니다.

3

지도 켜기

카카오맵→활성화 설정→ON
앱은 하나만 만드세요

무료 사용량은 계정에서 처음 켠 앱 하나에만 주어집니다. 두 번째 앱부터는 결제 등록을 요구합니다. 오디픽 앱 하나로 계속 쓰시면 됩니다.

4

주소 등록하기

앱→플랫폼 키→JavaScript 키→도메인 등록
개편 후에는 도메인을 키마다 등록합니다. JavaScript 키 추가 화면이 열리면 이렇게 채우세요.
키 이름 필수placepick-web
JavaScript SDK 도메인 http://localhost:8000 http://127.0.0.1:8000 한 칸에 하나씩입니다. 첫 칸에 하나 넣고 오른쪽 + 를 눌러 칸을 늘린 뒤 나머지를 넣으세요.
카카오 로그인 리다이렉트 URI 비워둡니다 우리는 지도만 씁니다. 카카오 로그인은 쓰지 않아요.
도메인을 한 칸에 몰아넣지 마세요

http://localhost:8000 http://127.0.0.1:8000 처럼 한 줄에 붙여 넣으면 둘 다 인식되지 않습니다. 반드시 칸을 나눠 주세요.

다 채우고 저장을 누르면 그때 키가 발급되어 아래에 나타납니다.

지도가 회색으로만 나온다면

거의 항상 이 단계를 빠뜨린 경우입니다. 등록하지 않은 주소에서는 지도가 뜨지 않습니다.

5

저에게 넘기기

REST API 키는 채팅 말고 파일로 주세요. 아래 위치에 파일을 만들고 한 줄만 적으시면 제가 읽어 씁니다.

claude-work/odipick/.env KAKAO_REST_KEY=여기에REST키붙여넣기

이미 만든 앱을 지우려면

실수로 앱을 여러 개 만드셨다면 필요 없는 것부터 지우면 됩니다.

앱→일반→앱 삭제
확인용으로 앱 이름을 그대로 입력해야 삭제 버튼이 눌립니다.
삭제가 안 되는 경우

카카오톡 채널이 연결돼 있거나, 테스트 앱이 남아 있거나, 비즈월렛이 연결돼 있으면 삭제되지 않습니다. 그 연결을 먼저 끊어야 합니다.

앱의 오너 계정으로 로그인해야 삭제할 수 있습니다.

키가 들어오면 바로 되는 것

지도가게 상세에 진짜 카카오맵이 뜨고 길찾기가 연결됩니다
자동 입력가게 이름만 넣으면 주소·좌표·전화번호가 자동으로 채워집니다
폐업 감지폐업하면 카카오에서 사라지므로 정확하게 잡아냅니다
주변 검색"지금 내 위치에서 가까운 곳"이 가능해집니다

카카오도 못 주는 것

룸 · 단체석 · 수용 인원 · 분위기 · 메뉴 가격은 카카오에도 없습니다. 주소·좌표·전화·카테고리·영업 여부까지입니다.

그 나머지가 오디픽에만 있는 정보고, 그게 이 서비스가 존재하는 이유입니다.

사용량 — 로컬 API 하루 10만 건 무료. 대전 음식점을 전부 훑어도 요금이 발생하지 않습니다.
